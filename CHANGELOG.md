# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/), and this project adheres to
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-20

### Added
- Single-file Magic 8 Ball web app (`index.html`).
- Realistic 3D ball with a recessed window and an inverted blue triangular die.
- 20 classic answers with the traditional 10 / 5 / 5 distribution.
- Six languages via a dropdown: English, Türkçe, Français, Deutsch, 日本語,
  العربية, with automatic right-to-left layout for Arabic.
- Auto-fitting answer text that scales to the triangle without breaking words.
- Prophecies (history) list with per-item delete and clear-all.
- Light / dark theme following the system preference, with a manual toggle.
- Responsive layout: fits one screen on desktop, tablet, and most phones;
  scrolls only on very short screens.
